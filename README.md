# Tripsync

Escapadas nos feriados da Bélgica, combinadas com amigos. Web app instalável (PWA) com login e dados no Supabase.

- `index.html`, `style.css`, `app.js`: o app
- `core.js`: feriados belgas e cálculo das escapadas
- `mapa.js`: mapa-múndi (Natural Earth 110m) e lista de países em português
- `config.js`: URL e chave pública do Supabase (a segurança vem das regras RLS do banco)

Publicado com GitHub Pages a partir da branch `main`.
